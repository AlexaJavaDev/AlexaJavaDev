---

### 🟢 Ступень 1. Фундамент

*Эти темы освоены на практике, продолжаю использовать и углублять в каждом новом проекте.*

**✅ Циклы и итерации:** `for`, `for-each`, `while` — свободное применение в любых задачах

**✅ Методы строк:** `String`, `StringBuilder` — регулярное использование, знание нюансов производительности

**✅ Массивы:** `int[]`, `String[]` и др. — уверенная работа, переход на коллекции где удобнее

**✅ ООП (база):** классы, объекты, конструкторы, геттеры/сеттеры, инкапсуляция

**✅ Исключения (база):** обработка базовых исключений (`try-catch`)

**✅ Scanner / Switch-case:** работа с вводом, современный синтаксис `->`

---

### 🟡 Ступень 2. Ядро языка (Углубление)

*Закрепляю и углубляю то, что уже знаю, и добавляю новые инструменты.*

**✅ (80/20) ООП (полная картина):** наследование, полиморфизм, `abstract`, `interface`, `default-методы`, `sealed`

**Исключения (полный цикл):** `checked/unchecked`, `throw/throws`, `finally`, кастомные исключения

**✅ Объектные контракты:** `equals/hashCode`, `Comparable/Comparator`

**Управление состоянием:** `static/final`, `enum`, `record`, `Optional`

**Generics:** `List<T>`, `? extends`, `? super`, свои generic-классы

---

### 🟠 Ступень 3. Инструменты и библиотеки

*Всё, что ускоряет разработку и делает код короче.*

**✅ (50/50) Коллекции (полный набор):** `ArrayList`, `HashSet`, `HashMap`, `TreeMap`, `Queue`, `Deque`

**Stream API + Lambda:** `filter`, `map`, `reduce`, `collect`, `groupingBy`, `flatMap`

**Работа с файлами:** `java.io`, `java.nio.file`, чтение/запись, сериализация

---

### 🔴 Ступень 4. Базы данных

*Хранение данных — ключевая часть серьёзных приложений.*

**✅ (20/80) SQL:** `JOIN`, `HAVING`, `GROUP BY`, индексы, транзакции, `EXPLAIN`

**JDBC:** `Connection`, `PreparedStatement`, `ResultSet`, миграции

---

### 🟣 Ступень 5. Многопоточность и инфраструктура

*Производительность, тестирование, сборка, контейнеризация.*

**Concurrency:** `Thread`, `Runnable`, `synchronized`, `ExecutorService`, `CompletableFuture`

**Тестирование:** JUnit 5, Mockito (unit-тесты, моки, `assertThrows`)

**✅ (30/70) Системы сборки:** Maven / Gradle (структура, зависимости, плагины)

**✅ (10/90) Docker:** Dockerfile, docker-compose, образы, контейнеры

**Алгоритмы и структуры:** Big O, стек, очередь, дерево, хеш-таблица

---

### 🔵 Ступень 6. Фреймворки и архитектура

*Выход на уровень Enterprise-разработки.*

**Spring Core (IoC/DI):** `@Component`, `@Autowired`, `ApplicationContext`

**Spring Boot + REST API:** `@RestController`, `@GetMapping`, `@PostMapping`

**Паттерны проектирования:** Singleton, Builder, Factory, Strategy, Observer
